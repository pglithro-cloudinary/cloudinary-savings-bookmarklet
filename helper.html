Measurement helper for the Cloudinary savings bookmarklet. This page is meant to be embedded in a hidden iframe. It performs the image size comparisons that the host page's Content-Security-Policy blocks, diagnoses anything that fails, and posts the results back to whoever framed it.

It can only read the size of a resource whose server explicitly opts in with an access-control-allow-origin header — the browser enforces that, not this page — so framing it grants no read access that the framing page didn't already have.
